Веб-платформа для командного/змагального ігрового заходу в жанрі HPG: сезони
(«забіги»), дошка з клітинок, випадкові випадання ігор, результати (пройдено /
завалено / перекидання), кидання костей і пересування дошкою, таблиця лідерів,
стрічка подій та адмін-консоль.

## Стек

- **Next.js 15** (App Router, Server Actions, RSC), строгий TypeScript
- **Tailwind CSS v4** + власна HUD-тема (естетика епохи GoldSrc, оригінальні асети)
- **PostgreSQL + Drizzle ORM** (міграції drizzle-kit)
- **Власна авторизація на cookie-сесіях** (scrypt-хеші, таблиця `sessions`) — без
  зовнішніх провайдерів
- **Zod** — спільні схеми (конфіг сезону валідується `SeasonConfigSchema` з рушія)
- **Vitest** — юніт-тести доменного рушія

## Можливості

### Для гравців

- **Командний центр** (`/dashboard`, після входу): випадання випадкової гри з
  пулу сезону (блєкліст і вже зіграні ігри ніколи не випадають), гра, потім
  позначення результату — **пройдено / завалено / перекидання**. Перекидання
  потребує причини та схвалюється рефері; просування дошкою застосовує ефекти
  клітинок (бонус, штраф, телепорт, подія…) і оновлює позицію, баланс і серії.
- **Дошка** (`/board`): мапа сезону — види «сітка» та «лінія», живі поточні
  кидки, деталі клітинок. **Лідери** (`/leaderboard`): місця за позицією та
  балансом. **Стрічка** (`/feed`): живий журнал подій із фільтрами (кидки,
  проходження, провали, ходи, вступи).
- **Правила** (`/rules`): правила поточного сезону, написані організаторами
  в Markdown.
- **Сезони** (`/seasons`): архів минулих і поточних забігів із підсвіткою
  активного сезону; детальна сторінка кожного сезону на `/seasons/[slug]`.
- **Профіль** (`/settings`): аватар (квадратний кроп) і широкий банер (3:1),
  біо, посилання на зовнішні профілі (Twitch/Steam/Discord/…), особистий
  акцентний колір і мова сайту. Публічний профіль — `/players/[username]`.

### Для організаторів (адмін-консоль, `/admin`)

- **Огляд**: статистика платформи, активний сезон, швидкі дії.
- **Сезони** (`/admin/seasons`): створення забігу (slug генерується
  автоматично, дошку можна склонувати з минулого забігу) та керування життєвим
  циклом `draft → active → paused → finished → archived` (активація скидає
  учасників).
- **Редактор сезону** — три вкладки на кожен сезон:
  - **Налаштування** (`/admin/seasons/[id]`): кості (грані, кількість на
    проходження/провал, множник серій), правила очок/балансу, розмір і
    зацикленість дошки, ліміти перекидань, джерело/провайдер ігрового пулу та
    Markdown-правила для /rules.
  - **Дошка** (`/admin/seasons/[id]/board`): редагування кожної клітинки —
    тип (старт/фініш/штраф/бонус/подія/телепорт/своя), підпис і сума.
  - **Гравці** (`/admin/seasons/[id]/players`): додавання учасників (із живим
    пошуком користувачів), інлайнове редагування позиції/балансу/статусу та
    видалення — кожна зміна потребує причини та потрапляє в аудит-лог.
- **Користувачі** (`/admin/users`): список, блокування/розблокування,
  видалення та ролі (admin/judge — судді не можуть керувати користувачами).
- **Каталог ігор** (`/admin/games`): ручне додавання ігор, **імпорт за
  посиланням із магазину** (Steam, GOG, Epic, itch.io, Humble — без
  API-ключа), пошук за зовнішніми API (RAWG/IGDB/Steam/GameSpot з ключами),
  блєкліст ігор у сезоні та масові операції в пулі.
- **Модерація** (`/admin/moderation`): схвалення/відхилення запитів на
  перекидання та запитів про завершення ігор — кожне з обов'язковою причиною.
- **Аудит-лог** (`/admin/audit`): кожна дія персоналу з пошуком, фільтрами за
  типом дії та періодами часу.
- **Налаштування сайту** (`/admin/settings`): глобальні налаштування та
  інтеграції API-провайдерів (ключі RAWG/IGDB/Steam/GameSpot, вихідний проксі) —
  можна налаштувати там або через змінні середовища.

## Швидкий старт

```bash
git clone https://github.com/NemoKing1210/ggrun.git
cd ggrun
pnpm install

cp .env.example .env        # заповніть DATABASE_URL, AUTH_SECRET, ...
pnpm db:setup               # схема + демо-сезон + перший адмін
pnpm dev                    # http://localhost:3000
```
