Веб-платформа для командного/соревновательного игрового события в жанре HPG:
сезоны («забеги»), доска из клеток, случайные выпадения игр, исходы (пройдено /
пройдено / переброс), бросок костей и перемещение по доске, таблица лидеров,
лента событий и админ-консоль.

## Стек

- **Next.js 15** (App Router, Server Actions, RSC), строгий TypeScript
- **Tailwind CSS v4** + собственная HUD-тема (эстетика эпохи GoldSrc, оригинальные ассеты)
- **PostgreSQL + Drizzle ORM** (миграции drizzle-kit)
- **Своя авторизация на cookie-сессиях** (scrypt-хеши, таблица `sessions`) — без
  внешних провайдеров
- **Zod** — общие схемы (конфиг сезона валидируется `SeasonConfigSchema` из движка)
- **Vitest** — юнит-тесты доменного движка

## Возможности

### Для игроков

- **Командный центр** (`/dashboard`, после входа): выпадение случайной игры из
  пула сезона (блэклист и уже сыгранные игры никогда не выпадают), игра,
  затем отметка исхода — **пройдено / не пройдено / переброс**. Переброс
  требует причины и одобряется рефери; продвижение по доске применяет эффекты
  клеток (бонус, штраф, телепорт, событие…) и обновляет позицию, баланс и
  серии.
- **Доска** (`/board`): карта сезона — виды «сетка» и «линия», живые
  выполняемые броски, детали клеток. **Лидерборд** (`/leaderboard`): места по
  позиции и балансу. **Лента** (`/feed`): живой журнал событий с фильтрами
  (броски, прохождения, провалы, ходы, вступления).
- **Правила** (`/rules`): правила текущего сезона, написанные организаторами
  в Markdown.
- **Сезоны** (`/seasons`): архив прошлых и текущих забегов с подсветкой
  активного сезона; подробная страница каждого сезона на `/seasons/[slug]`.
- **Профиль** (`/settings`): аватар (квадратный кроп) и широкий баннер (3:1),
  био, ссылки на внешние профили (Twitch/Steam/Discord/…), личный акцентный
  цвет и язык сайта. Публичный профиль — `/players/[username]`.

### Для организаторов (админ-консоль, `/admin`)

- **Обзор**: статистика платформы, активный сезон, быстрые действия.
- **Сезоны** (`/admin/seasons`): создание забега (slug генерируется
  автоматически, доску можно склонировать из прошлого забега) и управление
  жизненным циклом `draft → active → paused → finished → archived`
  (активация сбрасывает участников).
- **Редактор сезона** — три вкладки на каждый сезон:
  - **Настройки** (`/admin/seasons/[id]`): кости (грани, количество на
    прохождение/провал, множитель серий), правила очков/баланса, размер и
    зацикленность доски, лимиты перебросов, источник/провайдер игрового
    пула и Markdown-правила для /rules.
  - **Доска** (`/admin/seasons/[id]/board`): редактирование каждой клетки —
    тип (старт/финиш/штраф/бонус/событие/телепорт/своя), подпись и сумма.
  - **Игроки** (`/admin/seasons/[id]/players`): добавление участников (с живым
    поиском пользователей), инлайновое редактирование позиции/баланса/статуса
    и удаление — каждое изменение требует причины и попадает в аудит-лог.
- **Пользователи** (`/admin/users`): список, блокировка/разблокировка,
  удаление и роли (admin/judge — судьи не могут управлять пользователями).
- **Каталог игр** (`/admin/games`): ручное добавление игр, **импорт по ссылке
  из магазина** (Steam, GOG, Epic, itch.io, Humble — без API-ключа), поиск по
  внешним API (RAWG/IGDB/Steam/GameSpot с ключами), блэклист игр в сезоне и
  массовые операции в пуле.
- **Модерация** (`/admin/moderation`): одобрение/отклонение запросов на
  переброс и запросов о завершении игр — каждое с обязательной причиной.
- **Аудит-лог** (`/admin/audit`): каждое действие персонала с поиском,
  фильтрами по типу действия и периодами времени.
- **Настройки сайта** (`/admin/settings`): глобальные настройки и интеграции
  API-провайдеров (ключи RAWG/IGDB/Steam/GameSpot, исходящий прокси) — можно
  настроить там или через переменные окружения.

## Быстрый старт

```bash
git clone https://github.com/NemoKing1210/ggrun.git
cd ggrun
pnpm install

cp .env.example .env        # заполните DATABASE_URL, AUTH_SECRET, ...
pnpm db:setup               # схема + демо-сезон + первый админ
pnpm dev                    # http://localhost:3000
```
